한글 캘리그라피 체험·클래스

참가자가 붓으로 직접 한글을 써 보는 한국 문화 체험입니다. 박람회 체험 부스나 강의형 클래스로 운영하고, 외국인 참가자를 위해 영어로도 진행합니다.

붓으로 한글을 직접 써 보는 한국 문화 체험입니다. 박람회·국제행사의 체험 부스로 운영하거나, 강의형 클래스로 한글을 간단히 배우고 붓글씨를 연습한 뒤 부채에 한글 문구를 써서 완성합니다. 외국인 참가자를 위해 영어로도 진행합니다.

이런 행사에 좋아요

  • 국제행사·박람회의 K-컬처 체험 부스
  • 외국인 VIP·임직원 문화체험
  • 방한 연수단·국제교류 행사
  • 기업 임직원 클래스

구성

  • 체험 부스: 참가자가 붓으로 한글 써 보기, 또는 작가 시연으로 엽서에 한글 써 드리기
  • 클래스: 한글 기초, 작가 작품 감상, 붓글씨 체험, 부채에 한글 문구 쓰기
  • 한글 문구를 쓴 부채·엽서 기념품

클래스 진행 순서

  1. 한글 기초 배우기
  2. 작가 대표 작품 감상
  3. 붓글씨 체험
  4. 부채에 한글 문구 쓰기
  5. 완성한 부채 가져가기

준비할 것

  • 운영 형태(체험 부스 / 클래스)와 참가 대상
  • 외국인 참가자가 있으면 영어 진행 요청

자주 묻는 질문

외국인 참가자도 할 수 있나요?

영어로 진행합니다. 외국인 임직원·VIP, 방한 연수단 대상 클래스를 운영해 왔습니다.

참가자가 가져가는 것이 있나요?

한글 문구를 쓴 부채나 엽서를 기념품으로 가져갑니다.

해외 행사에도 올 수 있나요?

해외 박람회·전시회의 한글 캘리그라피 부스를 운영한 경험이 있어 출장 운영이 가능합니다.
